## 📖 About the Project
**BOBA t** is a cross-platform mental health tracking system designed to bridge the "data blackout" between therapy sessions. 

For **Patients**, it offers a low-friction environment log daily moods, activities, and journal entries in seconds.  
For **Therapists**, it provides a data dashboard to visualize patient progress and identify trends over time.

By synchronizing emotional data in real-time, Boba transforms therapy from a reactive weekly conversation into a proactive, data-informed journey.

## ✨ Key Features
* **Daily Check-ins:** "Daily Bean" inspired micro-journaling using intuitive sliders and activity icons.
* **Real-time Sync:** Patient data updates instantly on the Therapist’s dashboard via Firestore.
* **Data Visualization:** Native Swift Charts (iOS) and JS Charts (Web) transform raw logs into meaningful trend lines.
* **One-Tap Sessions:** Integrated deep-linking to secure video conferencing (Jitsi/Google Meet).
